# AGENTS.md

Dibs: used-PC-part marketplace. Shop test agent + Next.js site + native Solana escrow program (devnet).

## Commands (run in `web/`)
- Install: `npm install`
- Dev: `npm run dev` (or `npm run dev:lan` to listen on 0.0.0.0:3000)
- Build / start: `npm run build` / `npm run start`
- Lint: `npm run lint`; type-check: `npx tsc --noEmit`
- No test runner. `web/lib/escrow/math.check.ts` is a standalone self-check for the payout math.
- Escrow program: `cargo build-sbf --manifest-path program/escrow/Cargo.toml` (needs Agave; CI does this in `.github/workflows/escrow.yml`)
- Deploy + init on devnet (from repo root): `node web/scripts/devnet.mjs`

## Where logic lives
- `web/app/api/*` — agent upload, sessions, publish, verify, escrow routes
- `web/lib/db.ts` — storage: `web/data/db.json` locally, Upstash Redis when `KV_REST_API_*` / `UPSTASH_REDIS_REST_*` are set
- `web/lib/auth.ts` — staff cookie `dibs_staff`, password from `DIBS_ADMIN_PASSWORD`
- `web/lib/escrow/` — PDAs, instructions, payout math (`math.ts` must match `quote` in `program/escrow/src/lib.rs`)
- `web/public/dibs_agent.py` — Windows + NVIDIA test/verify agent, Python standard library only
- `web/components/admin/SessionLive.tsx` — live test view and publish form

## Conventions
- Next.js 16 has breaking changes: read `web/AGENTS.md` and `web/node_modules/next/dist/docs/` before writing Next.js code.
- Server components where possible, small components, Tailwind 4. Server-only modules import `"server-only"`.
- Keep both fingerprint formats unchanged (part: `sha256({"gpu": "uuid|vbios"})`; device: `sha256({"bios", "gpus"})`).
- Never put personal data on-chain (names, phones, raw BIOS serials); only hashes and test numbers.
- Program instruction tags (0–15) and account byte offsets in `lib.rs` are mirrored in the TS client; change both together.

## Do not touch / commit
- `keypairs/` (admin keypair, program ID), `.env*`, `web/data/`, `program/escrow/target/`, `web/.next/`, `node_modules/`
- `SHOP_KEYPAIR` is a secret signing key.
- The Next.js agent-rules block in `web/AGENTS.md` is regenerated by `next dev`.

## Gotchas
- Without `DIBS_ADMIN_PASSWORD`, dev uses a fallback password and production has no staff login at all.
- `confirm` only works after `mark_shipped`, and the buyer must sign; a Match from `/api/verify` never releases funds.
- Escrow timeouts are frozen at init (min 60 s). `ESCROW_TIMEOUT_SECS` affects only `devnet.mjs`.
- `BUILD-PROMPT.md` is a plan; Anchor and Supabase described there were not used.
- `docs/PITCH.md` contains historical Monad material; do not implement from it.
